# InfiniteBoard Pro

A simple online whiteboard where you can draw, make shapes, add text, and save your work.
<img width="1916" height="1001" alt="e4f602efc628934d466f7a205e1f23e879553b6670102dfdcfaf8c79d78f5ace" src="https://github.com/user-attachments/assets/143f36a1-2505-4c67-b2d1-7c1789a21397" />

## Features

- Infinite canvas
- Draw with a pen
- Add rectangles, circles, arrows, and text
- Select and move objects
- Change colors and stroke size
- Light and dark backgrounds
- Undo your last action
- Auto-save your work
- Import and export JSON
- Download drawings as SVG

## How to Use

1. Download the repository.
2. Open `index.html` in your browser.
3. Start drawing\!

## Controls

- Left Click - Draw or select
- Drag - Move objects
- Mouse Wheel - Zoom
- Space + Drag - Move around the canvas

## Built With

- HTML
- CSS
- JavaScript

## Note

Best used on a desktop browser.
